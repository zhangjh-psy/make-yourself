# Make yourself

> 一个纯离线的个人工作台：日历待办 · 截止日 · 倒数日 · 日记 · 慎独计时
>
> **当前版本 0.0.1（内测版）** —— 功能可用，但还在打磨，界面和数据结构都可能变。

数据全部存在你自己的电脑上，**不联网、不要账号、不采集任何东西**。

---

## 它解决什么问题

市面上的日程软件要么在云端（数据不在自己手里），要么功能太杂。这个工具只做一件事：
**把"我要做的事"和"我想成为的人"放在一个安静的界面里，数据留在本机。**

几个不太一样的地方：

- **截止日会自动挂一条待办**。新建"论文初稿 6 月 1 日截止"，它会在 6 月 1 日自动生成一条同名待办。
  这样截止日不会被忘在某个单独的模块里——翻日历就能看见。
- **倒数日支持真正的农历**。长辈生日按农历记，每年自动换算，还能算出"第几周年"（含闰月）。
- **卡片可以自己画形状**。倒数日有"版面"视图：像 PPT 一样自由摆放，形状能拖控制点改成任意多边形。
- **慎独计时**。记录每天沉浸的时间，可暂停、跨零点自动切分、带 7 天与本月统计。
- **数据就是一个 JSON 文件**。想备份就复制走，不需要数据库、不需要导出工具。

## 下载使用

到 [Releases](../../releases) 页下载。两种选一个：

| 文件 | 适合 | 说明 |
|---|---|---|
| **`MakeYourself-安装版-x.y.z.exe`** | 长期使用（推荐） | 走安装向导，自动建桌面/开始菜单图标，装完**秒开**，可在「添加或删除程序」里正常卸载 |
| **`MakeYourself-便携版-x.y.z.exe`** | 只想试试 | 免安装，双击即用。首次启动约需 10 秒（要自解压），不留系统痕迹 |

**系统要求**：Windows 10 或更高版本（x64）。

**首次运行会看到蓝色的「Windows 已保护你的电脑」**：
这不是病毒——是因为这个项目没有购买代码签名证书（个人项目通常都不买）。
点 **「更多信息」→「仍要运行」** 即可。

**升级**：直接下载新版安装即可，会覆盖旧版。**你的数据不会被动**（程序和数据在两个不同的文件夹里）。

## 从源码运行

需要 Node.js 18 以上。

```bash
git clone https://github.com/zhangji-psy/make-yourself.git
cd make-yourself
npm install
npm start          # 构建并启动
```

| 命令 | 作用 |
|---|---|
| `npm run build` | 只构建（esbuild，约 0.5 秒） |
| `npm run typecheck` | 类型检查 |
| `npm run verify` | **算法自检**（88 条断言：农历、重复规则、截止日状态…） |
| `npm run icon` | 重新生成图标 |
| `npm run sync:public` | 把改动同步到公开仓库那份（见下） |
| `npm run pack` | 打包成便携版 exe |
| `npm run dist` | 打包成安装包 |

### 开发用的两个自检

改完代码推荐跑一遍，能确认没把别的地方弄坏：

```bash
# 算法自检（88 条）
npm run verify

# 启动自检（185 条）：程序会自己点按钮、输入、拖拽、改形状，再核对数据文件
node_modules\electron\dist\electron.exe . --diag --user-data-dir=临时目录
```

## 功能一览

### 首页 / 慎独
- 自定义一句话（内容、字号、粗细、颜色、位置、对齐）
- 自定义背景：跟随主题 / 纯色 / 渐变 / **本地图片**（自动压缩，可加暗色蒙版）
- **慎独计时**：`开始慎独 → 暂停 → 继续慎独`，去任何板块都继续算，退出应用才停表
- 编辑面板里带最近 7 天柱状图 + 本月热力图 + 本月累计

### 日历
- 月 / 周两种视图，格子显示农历、节日节气、待办进度、心情、📌 截止日
- 待办可勾选、**拖拽改期**、设截止时间（过期高亮）
- 重复待办：每天 / 工作日 / 每周 / 每月。**每次的完成记录独立**，勾了这周不会影响上周
- 顶部可折叠的截止日区

### 截止日
- 进度条 0~100%（推到 100% 自动标记完成）
- 剩余状态：`还有 5 天` / `今天到期` / `已过期 3 天`，颜色分级
- 紧急程度、标签、备注、子待办
- **新建时自动在截止当天生成一条待办**

### 倒数日
- 正数 / 倒数双模式；生日类附注"第 N 周年"
- **农历**：闰月支持、每年自动重算
- **精确倒计时**到时分秒
- 重复：不重复 / 每年公历 / 每年农历 / 每月 / 每周
- 置顶、颜色、emoji、分类
- **列表视图**：按住卡片拖动排序
- **版面视图**：16:10 画布自由摆放，拖位置 / 拖大小 / 对齐辅助线；卡片形状 10 种预设，还能**拖控制点自定义成任意多边形**；背景纯色 / 渐变 / 图片；三组文字颜色与字号；10 个显示项开关；样式可一键复制给别的卡片

### 日记
- 心情 emoji、标签、日记正文（自动保存）
- 迷你月历（有内容的日子显示心情或圆点）+ 日记时间线 + 搜索
- 日历格子上仍显示心情，一眼看出这个月状态

### 提醒与后台
- 倒数日提醒（每条可单独设提前几天：30/14/7/3/1/0）
- 开机自启、托盘常驻、每日早间汇总、桌面悬浮窗 —— **全部可单独开关**

### 数据安全
- 数据文件：`%APPDATA%\Make yourself\workbench-data.json`（**一个文件**）
- **原子写入**（先写临时文件再改名，断电不会写坏）
- **每天自动备份**，保留最近 30 份；主文件损坏时自动尝试用备份恢复
- 一键导出 JSON（完整可恢复）+ Markdown（可读）
- 一键导入还原
- 升级程序时**老数据自动兼容**，需要改结构时有版本迁移机制

## 技术栈

| | |
|---|---|
| 桌面框架 | Electron 44 |
| 界面 | React 19 + TypeScript |
| 构建 | esbuild（自写构建脚本，不用 Vite/Webpack） |
| 数据 | 单个 JSON 文件 + 原子写入 |
| 农历 | [lunar-javascript](https://github.com/6tail/lunar-javascript) |
| 打包 | electron-builder（安装包 + 便携版） |

**运行依赖只有 3 个**：`react`、`react-dom`、`lunar-javascript`。
图标、图表、形状渲染、PNG/ICO 编码器、状态管理全部手写，没有引入额外库。

代码结构、数据流、以及踩过的坑（农历换算、SVG 形状裁切、中文编码、计时状态…）
见 **[ARCHITECTURE.md](./ARCHITECTURE.md)**。

## 已知限制

- **仅支持 Windows 10+**。托盘、通知、快捷方式、开机自启都用了 Windows 原生能力
- **没有自动更新**。新版本需要到 Releases 页手动下载覆盖安装（数据不受影响）
- **首次运行有安全提示**，因为没买代码签名证书
- **内测阶段**：0.0.x 期间数据结构和界面都可能调整，升级前建议先导出备份
